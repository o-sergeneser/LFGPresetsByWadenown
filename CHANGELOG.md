# Changelog

## 1.0.1 - LFG Templates

### Updated interface

- Renamed the addon display name and all in-game preset labels to **LFG Templates** and **Template** in menus, panels, tooltips and dialogs.
- Added **/lft** and **/lfgtemplates** to open settings. **/lfp** and **/lfgpresets** continue to work.

### Group Finder tab

- Moved the **LFG Templates** tab beside the other bottom tabs, away from the Sign Up button.
- The tab finds the rightmost visible tab and follows its position as tabs are shown, hidden or resized, including different UI scales.
- Reduced horizontal padding and corrected spacing between neighboring tabs.
- Added a small addon icon beside the tab label while keeping the neighboring tabs' font.

### Artwork and saved templates

- Updated the in-game icon with the supplied native 32-pixel artwork.
- Added the new **LFG Templates** artwork for the CurseForge project page.
- Fresh installations start with **five empty slots per category**, ready for your own templates.
- Existing templates and preferences are retained through the update. Account-wide storage and the addon installation folder remain compatible with version 1.0.0.

## 1.0.0

- Account-wide application, dungeon and raid presets with expandable slot lists.
- Classic and Modern themes, English and Turkish interfaces.
- Manual copy workflow with automatic draft saving on Ctrl+C.
- Configurable panel attachment, locking, preview, scale and opacity.
- Optional native application note retention.
- Bundled PT Sans Narrow Bold and addon icon.
- Cached text previews and font updates, UTF-8-safe binary-search truncation.
