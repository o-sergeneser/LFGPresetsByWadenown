# Changelog

## 1.0.0

- Account-wide application, dungeon and raid presets with expandable slot lists.
- Classic and Modern themes, English and Turkish interfaces.
- Manual copy workflow with automatic draft saving on Ctrl+C.
- Configurable panel attachment, locking, preview, scale and opacity.
- Optional native application note retention.
- Bundled PT Sans Narrow Bold and addon icon.
- Cached text previews and font updates, UTF-8-safe binary-search truncation.
